# College-Project-Management-System-using-Django-Framework
Developed a College Project Management System using Python (Django), HTML, CSS, and SQLite. Implemented CRUD operations for projects and students, secure login/register system, and project assignment functionality. Designed database models using Django ORM and created an admin dashboard to manage users and projects efficiently. 

A web-based application built using Python (Django), HTML, CSS, and SQLite to manage academic projects efficiently. The system allows administrators to create, edit, delete, and assign projects to registered students. It includes a secure login system, CRUD operations for projects and users, and an admin dashboard for easy management.

Features:

User Registration & Login

Add, Edit, Delete, and Assign Projects

Admin Dashboard for Managing Users & Projects

View Project Details and Assigned Students

Tech Stack:

Backend: Python, Django

Frontend: HTML, CSS

Database: SQLite
